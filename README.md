# Italian Web

A small mobile-friendly practice page for Italian listening.

Tap any timed line to jump to that stretch of audio. Use **Loop segment** to repeat it, or **Stop at end** to practice one phrase at a time.

## Local

Open `index.html` with a local server (needed so the `.srt` file can load):

```bash
npx serve .
```

## GitHub Pages

This site is published from the `main` branch root.
